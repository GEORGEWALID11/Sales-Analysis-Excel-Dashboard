# 📊 Sales Analysis Dashboard

## 📌 Project Overview

Sales Analysis Dashboard is a data analytics project developed using **Microsoft Excel** to transform raw sales data into meaningful business insights through data cleaning analysis and visualization

The project focuses on analyzing sales performance customer behavior product performance and revenue trends to support better business decision making

The dataset consists of three main areas

- **Customers** — Customer information and demographics
- **Orders** — Order details dates quantities and revenue
- **Products** — Product names categories and prices

## 🔍 Key Analysis Areas

- Monthly revenue trends and sales performance
- Revenue generated by different products
- Sales performance across product categories
- Customer ordering patterns and geographical distribution
- Order distribution based on different occasions
- Revenue distribution across different hours of the day
